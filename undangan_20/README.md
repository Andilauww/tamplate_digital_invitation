# Undangan Pernikahan Raka & Sinta — Elegant Royale

Template undangan pernikahan digital bertema **Elegant Royale** dengan palet Midnight Sapphire Navy (`#0C1A33` / `#13284A` / `#1F3C6B`), Champagne Gold (`#DFC092`), dan Alabaster Ivory (`#FBF3E8`).

## Struktur Folder

```
undangan_20/
├── index.html              # Struktur utama halaman web (HTML5)
├── css/
│   └── style.css           # Styling kustom, animasi pintu 3D, lentera & ornamen royale
├── js/
│   ├── tailwind.config.js  # Konfigurasi tema Tailwind (navy, sapphire, champagne gold, ivory)
│   └── script.js           # Logika interaktif (Audio, Countdown, Buku Tamu, RSVP, Lightbox)
├── asset/
│   ├── img/mempelai/       # Foto editorial & komposit bingkai royale
│   ├── img/ornamen/        # Ornamen ukiran, lentera, mega mendung & bingkai royale
│   └── music/              # Audio latar pernikahan
└── README.md               # Dokumentasi proyek
```

## Cara Menjalankan

Buka `index.html` langsung di browser atau jalankan melalui Live Server.
