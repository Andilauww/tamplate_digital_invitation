# Undangan Pernikahan Raka & Sinta — Dreamy Floral

Template undangan pernikahan digital bertema **Dreamy Floral** dengan palet Pearl White (`#F7F9FE`), Periwinkle Mist (`#8FA9D4`), Cornflower Blue (`#5D7BB4`), dan Midnight Ink (`#152544`).

## Struktur Folder

```
undangan_22/
├── index.html              # Struktur utama halaman web (HTML5)
├── css/
│   └── style.css           # Styling kustom, animasi pintu 3D, bingkai & efek kabut floral
├── js/
│   ├── tailwind.config.js  # Konfigurasi tema Tailwind (pearl white, periwinkle, cornflower, midnight ink)
│   └── script.js           # Logika interaktif (Audio, Countdown, Buku Tamu, RSVP, Lightbox)
├── asset/
│   ├── img/mempelai/       # Foto editorial & komposit bingkai lengkung Dreamy Floral
│   ├── img/ornamen/        # Ornamen buket sudut cat air biru, garis sudut floral & pembatas
│   └── music/              # Audio latar pernikahan
└── README.md               # Dokumentasi proyek
```

## Cara Menjalankan

Buka `index.html` langsung di browser atau jalankan melalui Live Server (`npm start`).
