## Fitur Utama

1. **Audio Web API Synthesizer**: Pemutar musik lembut akor romantis langsung lewat Web Audio API bawaan browser (tanpa perlu file MP3 eksternal).
2. **Countdown Timer**: Hitung mundur otomatis menuju hari bahagia (24 Mei 2025).
3. **Buku Tamu & Ucapan (Live Guestbook)**: Formulir ucapan dengan penghitung karakter, kartu ucapan interaktif, dan tombol suka (like).
4. **Konfirmasi Kehadiran (RSVP)**: Formulir kehadiran yang beralih mulus ke tampilan ucapan terima kasih.
5. **Galeri & Lightbox**: Pratinjau foto momen bahagia berukuran besar saat diklik.
6. **Animasi Flora Organik**: Efek goyangan daun, pampas, dan bunga anggrek bertingkat yang terasa hidup.
7. **Responsif Sepenuhnya**: Tampilan optimal untuk smartphone, tablet, maupun layar desktop, lengkap dengan navigasi bawah (bottom navigation) untuk mobile.

## Cara Menjalankan

Cukup klik dua kali (double click) file index.html untuk langsung membukanya di browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll). Tidak memerlukan instalasi server atau npm.
