# 💍 Undangan 11 TF — Baralek Gadang Adat Minangkabau (Tanpa Foto) (`undangan_11_tf`)

Template undangan pernikahan digital bertema **Adat Minangkabau (*Baralek Gadang Ranah Minang*) Tanpa Foto (TF)** dengan karakter ilustrasi 2D Chibi otentik Nusantara berpakaian adat Minang (*Saluak Marapulai*, *Suntiang Gadang Anak Daro*, *Songket Pandai Sikek Maroon*, dan *Emas Makau 24K*).

---

## ✨ Fitur & Keunggulan Desain

1. **Ilustrasi Chibi Adat Minangkabau 1:1 (`asset/*-minang-chibi.jpg`)**:
   - **Cover & Hero (`cover-minang-chibi.jpg`)**: Karakter chibi pasangan Minang berdiri berdampingan lengkap dari kepala hingga kaki, Marapulai mengenakan Saluak songket dan Anak Daro mengenakan hijab anggun bermahkota Suntiang Gadang.
   - **Mempelai Pria (`mempelai-pria-chibi.jpg`)**: Potret setengah badan Marapulai dengan Saluak adat dan kerah Baju Gadang bersulam benang emas.
   - **Mempelai Wanita (`mempelai-wanita-chibi.jpg`)**: Potret setengah badan Anak Daro berhijab dengan mahkota Suntiang Gadang bertingkat dan buket bunga mawar putih.
   - **Penutup (`footer-minang-chibi.jpg`)**: Potret pasangan dalam bingkai pelaminan Minang.

2. **Tata Letak & Standar Bebas Foto (TF)**:
   - **Perjalanan Cinta (Cerita Cinta)**: Kartu kisah 3 babak bernuansa Minang dengan lencana ikon tematik (*Heart*, *Ring*, *Award*) tanpa placeholder foto asli.
   - **Navigasi Dockbar 4 Menu**: Disesuaikan khusus versi tanpa foto (`#beranda`, `#mempelai`, `#acara`, `#ucapan`).
   - **Tanggal & Lokasi 2 Baris**: Sesuai aturan baku, diformat 2 baris terpusat pada Gate Cover.
   - **Tombol Instagram Simetris**: Ukuran presisi (`height: 38px`, `padding: 0 20px`, `gap: 8px`).
   - **Desktop Ambient Wings**: Ornamen sayap samping dan sudut Kaluak Paku & Marawa dengan animasi mengambang halus 8 detik dan dukungan `prefers-reduced-motion`.

---

## 🚀 Cara Menjalankan

```bash
npm start
```
Atau buka `index.html` menggunakan Live Server. Gunakan parameter `?to=Nama+Tamu` pada URL untuk personalisasi nama tamu.
