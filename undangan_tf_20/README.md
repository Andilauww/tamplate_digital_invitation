# Undangan Pernikahan Raka & Sinta — Elegant Royale (Seri Tanpa Foto)

Template undangan pernikahan digital seri **Tanpa Foto (`tf`)** bertema **Elegant Royale** dengan palet Midnight Sapphire Navy (`#0C1A33` / `#13284A` / `#1F3C6B`), Champagne Gold (`#DFC092`), dan Alabaster Ivory (`#FBF3E8`), menggunakan ilustrasi chibi pasangan berbusana Beskap & Kebaya Jawa Beludru Navy bersulam Champagne Gold.

## Struktur Folder

```
undangan_tf_20/
├── index.html              # Struktur utama halaman web tanpa bagian galeri foto
├── css/
│   └── style.css           # Styling kustom, animasi pintu 3D, lentera & ornamen royale
├── js/
│   ├── tailwind.config.js  # Konfigurasi tema Tailwind (navy, sapphire, champagne gold, ivory)
│   └── script.js           # Logika interaktif (Audio, Countdown, Buku Tamu, RSVP)
├── asset/
│   ├── img/mempelai/       # Ilustrasi chibi transparan, potret lingkaran & komposit Hero
│   ├── img/ornamen/        # Ornamen ukiran, lentera, mega mendung & bingkai royale
│   └── music/              # Audio latar pernikahan
└── README.md               # Dokumentasi proyek
```

## Cara Menjalankan

Buka `index.html` langsung di browser atau jalankan melalui Live Server.
